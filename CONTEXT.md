# Flash Cache

Кеш хранит значения с ограниченным сроком жизни. Допустимые устаревшие значения могут использоваться во время обновления.

## Язык

**Fresh (свежее значение)**:
Значение, для которого ещё не наступило время обновления и не истёк срок жизни.

**Stale (устаревшее допустимое значение)**:
Значение, время обновления которого наступило, но срок жизни ещё не истёк. Оно пригодно для выдачи читателю во время обновления.

**Expired (значение с истёкшим сроком жизни)**:
Значение, срок жизни которого закончился. Оно непригодно для выдачи читателю.
